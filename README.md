  # Call Outcome Analyzer

A simple Python CLI tool to analyze and categorize call outcomes.

## Features
- Record call outcomes
- Classify outcomes as successful, follow-up, or failed
- Display a summary report

## Why this project
This project demonstrates text processing, decision-making logic, and
data summarization — similar to preprocessing steps used in call automation
systems.

## How to run
```bash
python call_outcome_analyzer.py
